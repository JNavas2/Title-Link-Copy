Title-Link Copy

Advanced copying of web page and link Titles and/or Links.
Includes ability to copy as Hyperlink.
Toolbar or context menu on desktop, popup on Android.

How it works:

  • 🖥️ Desktop Toolbar icon or Page context menu → Page Title and/or Link
  • 🖥️ Desktop Link context menu → Link Text and/or Link URL
  • 📱 Android Popup → Current Page Title and/or Link
  • ⚙️ Options AP-style Title casing, Include Selected text
